# Confere Repasse

Demo de portfólio (iFood GenAI — AI Engineer): agente que confere o repasse de um restaurante parceiro. Dados fictícios.

## Rodar local

```bash
cp .env.example .env   # já contém as chaves públicas do Supabase
npm install
npm run dev
```

Build: `npm run build`
